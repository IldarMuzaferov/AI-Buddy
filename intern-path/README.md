# Путь стажёра

Фронтенд AI-помощника для онбординга. React, TypeScript в строгом режиме, TanStack Query, Zustand, Zod и Vite.

## Запуск

Требуется Node.js 22.12+ и npm. В каталоге проекта выполните:

```bash
npm ci
npm run dev
```

Откройте адрес из терминала (обычно [localhost:5173](http://localhost:5173)). По умолчанию включён **мок-режим**. Выберите Анну Соколову для основного сценария, Диму Орлова для пустых состояний или Бориса для кабинета наставника.

Чтобы подключить бэкенд, запустите сервер из вашего проекта по адресу `http://localhost:8000` и выберите **Локальный сервер** на экране входа или в меню профиля. Переключение завершает текущий сеанс. Запросы идут на `/api` через прокси Vite. Другой адрес можно задать в `.env.local` через `API_PROXY_TARGET`, затем перезапустить Vite. Пример настроек лежит в `.env.example`.

В мок-режиме все операции выполняет локальный адаптер. Изменения демо-данных сохраняются в браузере. «Служебная панель → Сбросить демо» восстанавливает исходные данные. В серверном режиме запросы направляются в бэкенд, а ошибки отображаются в интерфейсе.

## Сборка

```bash
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`. Vite Preview проксирует `/api` как dev-сервер. Для статического размещения настройте проксирование `/api` на бэкенд или укажите `VITE_API_BASE_URL` перед сборкой и настройте CORS на сервере.

## Код

| Слой                   | Что находится в нём                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| `src/app`              | Точка входа, провайдер TanStack Query, навигация по страницам, стили прототипа                   |
| `src/pages`            | Вход, главная, задачи, чат, знакомства, журнал, приватность, наставник, заявки, служебная панель |
| `src/widgets`          | Боковая панель, верхняя строка, сводка задачи и отображение переписки                            |
| `src/features`         | Отправка сообщений и SSE, подтверждение заявок, чек-лист и практика, уведомления                 |
| `src/entities/session` | Zustand-состояние сеанса и переключателя, контекст запросов и мутаций                            |
| `src/shared`           | Zod-схемы, клиент API, HTTP/SSE-транспорт, моки, базовые компоненты                              |

Методы из [API.md](./API.md) сгруппированы в `src/shared/api/endpoints.ts`. Оба режима используют одни схемы ответа. Вложения отправляются как `multipart/form-data`, чат читает SSE через Fetch, а журнал скачивает PDF. Токен хранится в памяти на время текущего сеанса. Dev-панель появляется, если `GET /health` возвращает `dev_mode: true`.

Логотип, иллюстрация, иконки, брендовые шрифты и основные стили перенесены из `prototype.html`. Шрифт DejaVu Sans в `public/assets/export-font.ttf` используется для кириллицы в локальном PDF.
